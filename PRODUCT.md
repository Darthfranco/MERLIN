# MERLIN prototype

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Owner confirmed a simple local browser UI with a small Node.js server on October 26, 2026. Plain HTML, CSS, and JavaScript keep this test harness dependency-free. This does not select MERLIN's final application platform.

## Users and purpose

The owner is testing typed requests → Meta understanding/tool selection → execution → text response. The first requested tools are internet search and multiple labeled timers. Success means an observable, functional loop, not a polished product design.

## Capabilities and constraints

No voice input or speech output in this slice. Keep actual tool results visible, persist timers with cancellation and explicit time zones, and keep credentials and private runtime data out of GitHub. Use Meta meaningfully; do not use Contributor variants for household data. The full ten-area product scope and unresolved choices remain in [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md).

## Brand commitments

MERLIN is a useful home assistant. The owner explicitly asked for a simple functional test UI; no character integration or visual redesign is required here.

## Evidence on hand

Product/hackathon/model references are in `docs/`. Blender assets are separate. Live Meta access must be verified using local credentials; scripted tests are not live-model evidence.
