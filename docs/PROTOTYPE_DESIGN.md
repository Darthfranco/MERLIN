# Text prototype surface

Mode: Operate. Owner-pinned direction: simple and functional, no visual concept round or generated comp needed for this test harness.

A single page presents a typed conversation and adjacent timers. On small screens these stack. The composer, current connection state, and running timers remain easy to find. Tool execution and citations appear with the reply. Timer expiry is an ordinary state change, never another model call.

Use system typography, readable light surfaces, blue controls, visible focus, semantic labels, and text statuses. The first viewport should let the owner enter a request and inspect timers immediately. Empty, busy, API-unconfigured, failed, running, completed, and cancelled states must be truthful. A manual timer form allows engine testing before credentials are configured and is explicitly labeled as bypassing Meta.

No voice, remote deployment, authentication, memory management, or character integration is claimed. This surface is temporary test infrastructure and does not define the final MERLIN interface.
