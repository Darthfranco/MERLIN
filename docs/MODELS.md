The separate lab implements local activation/turn detection → Meta transcription → Fenrir echo; reasoning, tools, and household learning remain disconnected. Wake-word detection does not authorize uploading or learning from unrelated room conversations. Muse Voice Transcribe handles speech input; it does not synthesize speech. ## Text-prototype API contract

The implementation calls `POST https://api.meta.ai/v1/responses`, with standard model IDs, `store:false`, encrypted reasoning replay, flat function definitions, and actual function-call outputs. Web search runs within Meta and returns execution events and URL annotations; timer creation/list/cancel runs in MERLIN after validation. See [Responses](https://dev.meta.ai/docs/protocols/responses), [tools](https://dev.meta.ai/docs/tool-calling), and [search](https://dev.meta.ai/docs/search-grounding), checked October 26, 2026.

Compound requests now enable `parallel_tool_calls:true` so Meta can emit several timer functions together and combine them with built-in search. A shared per-request search budget is passed as `max_tool_calls` on each model round; local calls and rounds are separately bounded. A live standard Spark 1.3 request created ten timers and answered two distinct searches with NASA/NOAA citations on October 26, 2026. This verifies a representative combined flow, not every possible prompt.

The API key stays in ignored server configuration. Standard mode does not use content for training; Meta terms still permit some retention. `store:false` is not ZDR, and separately enabled [ZDR disables web search](https://dev.meta.ai/help/policies-and-privacy/zero-data-retention). No Contributor model or alternate-provider fallback is enabled.

Timer rules distinguish `timer_default_seconds`, an integer from 1 to 604800 for an entirely omitted duration, from `timer_default_unit`, which fills only a missing unit for a stated number. The model sends `duration:null, unit:default` for a bare timer request and a positive amount with `unit:default` for a missing unit; zero is invalid. Conflicting defaults block only requests that need them, while an explicit amount and unit can proceed subject to other restrictions. A narrowly matched declaration such as “default timer is five minutes,” optionally followed by “set me a timer,” and a bare start with an existing whole-duration default can use the local path. It first performs the same memory-context selection as the model path and falls back to Meta whenever any household facts, preferences, or guidance are selected. Otherwise it performs the same sourced save, rule checks, real timer execution, persistence, and output checks without asking Meta to restate the result. Other wording and routine-expanded requests retain the normal model/tool loop.

Native web search is initially withheld. A local `prepare_web_search` function checks current saved restrictions before search becomes available on the next model round. This adds a round to searches, while ordinary replies require no separate memory-check model call. Exact output violations on the model path allow one tool-free repair attempt; the simple local timer path uses checked local fallback wording. Exact routine activations expand before the main-model call; non-exact suggestions use that existing call plus local confirmation guards. ## Voice development lab — October 27, 2026

The owner selected **Fenrir** from the linked Kokoro demo for a separate local echo lab. Speech recognition uses standard **`muse-voice-transcribe-1.0`**, whose account model-list access has been verified. Recorded mono PCM16 WAV is sent to `POST /v1/asr/transcribe` in `PUSH_TO_TALK` mode, following the [official speech guide](https://dev.meta.ai/docs/speech-to-text) and [file API reference](https://dev.meta.ai/docs/api-reference/voice/transcribe). This is transcription, not language translation or assistant reasoning.

Speech output uses the official **`hexgrad/Kokoro-82M`** model through its Python `KPipeline`, fixed to **`am_fenrir`**, running locally after setup. This selects the development voice; final product deployment remains open. No public Hugging Face inference service receives the text. The lab does not load household memory or invoke Spotify.

The later update adds **MERLIN-only local keyword spotting** through sherpa-onnx’s small Zipformer keyword model and **Silero VAD**. These detect activation/turns; Meta still transcribes speech. Explicitly enabled browser capture sends 16 kHz PCM to the loopback process, retaining a four-second raw-audio ring in RAM. Unrelated standby audio invokes no Meta calls. Completed activated clips upload after approximately 1.1 seconds of silence. A detected wake-only utterance can require one short transcription; removing the leading MERLIN leaves the session waiting without TTS. This avoids dropping real short commands based on unreliable keyword token timestamps.

Speech during STT/TTS cancels stale output and preserves unfinished audio for continuation; speech during playback starts a new turn. Follow-ups need no repeated MERLIN during a 10-second quiet window after playback, extended to 15 seconds after an interruption or resuming after at least eight seconds of quiet. This uses local timing context, not semantic classification or another model call. Sustained quiet returns to local wake processing; goodbye/thanks/end-phrase keywords no longer terminate sessions. A 400 ms onset grace, included within the 10/15-second windows, protects speech beginning near timeout, and duplicate playback-finished events do not restart the countdown. Development guards limit conversations to three minutes and 12 transcription attempts, including interrupted attempts, with 60 seconds per accumulated utterance. Mic-off, Clear, page hiding/exit, or connection failure releases capture/listener state. No speech/transcript files or household traces are written. False wakes and physical speaker/microphone echo cancellation remain unverified.

Kokoro delivery uses its [documented punctuation, native stress, and speed controls](https://huggingface.co/spaces/hexgrad/Kokoro-TTS/blob/main/app.py), with bounded local sentence pacing/pauses. Natural (default), Neutral, Lively, and Gentle preserve words and Fenrir; `[so](+2)` demonstrates native emphasis. No trained emotion parameter, semantic rewrite, pitch-shifted voice, or extra Meta call is claimed. Real offline synthesis produced valid audio for all four presets.

Detector runtimes are pinned to `sherpa-onnx`/`sherpa-onnx-core` `1.12.35` and SentencePiece `0.2.1`. Keyword/Silero bytes are SHA-256 pinned by `scripts/voice-listener-setup.py`; see [VOICE.md](VOICE.md#sources-and-dependencies) for sources/licenses. `ws` `8.22.0` supplies loopback WebSocket transport. `npm run check:voice-session` passed with authored synthetic audio: zero idle uploads and three active Meta clips (wake-only, full phrase, follow-up), without microphone access or saved audio. This consumes transcription credits and does not establish room-acoustic performance.

Meta’s [data commitments](https://dev.meta.ai/legal/commitments), checked October 27, state Standard Services content is not used to train Meta models while retention and safety processing can still apply. This lab does not enable or claim ZDR. The ASR API has no documented Responses-style `store:false` switch, so none is invented.
