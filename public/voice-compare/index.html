What the timings mean

Models run one at a time. The first pass starts a new worker; the warm repeat reuses its loaded model and voice reference. Each worker is released before the next model.

Total wait is measured at the local server, from request to the completed WAV. Generation excludes model loading and reference preparation. Audio length is measured from the WAV. A generation ratio below 1× is faster than playback.

Audio is played after the full file finishes. A model’s internal first-chunk time, when available, is diagnostic only—it is not browser playback latency. Initial Core ML compilation can make a first-ever run much slower. These are Mac measurements, not iPad benchmarks.

Text, voice references, and generated audio stay in this local test’s storage. No Meta calls, microphones, household memory, or device actions. Model setup downloads are separate.
