# MERLIN voice comparison

Mode: Operate. A separate local test surface in the existing voice lab’s utility design system. It does not select the production assistant UI or voice.

The primary task is entering one passage, choosing models, then listening to measured results. A single white workbench holds inputs. Full-width model rows put first-request and warm-repeat audio beside their timing breakdown; mobile stacks the two passes. Reference preparation and timing methodology stay in disclosures below the results.

Use the established pale gray background, white surfaces, navy text, blue actions, system sans-serif, visible 44px controls, and native audio players. Body text is 14–16px, supporting measurements 12–14px, model headings 16px, section headings 18px, and the page heading 32px (26px on narrow screens). Timing numerals are tabular. Colors and focus styles inherit public/voice/voice.css. No imagery, external fonts, decorative animation, or assistant character is required for this test.

All measurements come from real worker responses and validated WAVs. Empty, running, interrupted, cancelled, unavailable, and failed states have explicit wording. Polling preserves playing audio nodes. Saved custom reference audio stays separate from the fixed Kokoro Fenrir baseline. Source links identify each actual model; runtime labels distinguish Mac execution from untested iPad performance.
