    Routines and trigger phrases

    Save a name or phrase that stands for a longer request. An intentional command runs that saved request once, using the available tools and current rules. A question about a trigger does not start its routine; a close match asks for confirmation.

    Add or edit a routine

    One phrase per line, up to 12 phrases of 120 characters each. The name itself is also a trigger.
