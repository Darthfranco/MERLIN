# MERLIN robot screen panels

Operate. Seven 5:6 screens for the existing pulled-out robot panels: countdown only, lights, oven, music, schedule confirmation, routine confirmation, and routine detail. The owner requested a super simple on-theme design and simple cartoon Muse routine imagery. This is an extension of the white, blue, cyan, matte character world, not a replacement brand or final app-platform decision.

One large value or state leads each screen, followed by necessary context and minimal actions. A quiet collection makes all seven visible; detail mode has real keyboard/touch preview controls. The signature is one canvas painter shared by the flat preview, PNG export, and both actual model panels, including dismissal fragments. Routine artwork is associated through an art key; the first synthetic Tea time example was generated by standard Muse.

Everything here uses labeled synthetic data. No device/scheduler/music or actual stored-routine changes occur. Saved/viewed routines do not execute. Unknown and unavailable states suppress action controls. Real integration must use verified results, explicit recurrence/time zone, and existing rule checks. Production assistant wiring and automatic artwork lifecycle remain open.

Independent finish review: ship, with no required visual fixes. Reviewed desktop and 390px detail/collection captures and actual right-panel model capture. The left timer panel was also visually verified. Scoped visual and API references are DESIGN.md and README.md.
